# Hogar Seguro

Startup de domótica y seguridad residencial que centraliza en una app móvil los datos de sensores IoT del hogar (gas, humo, temperatura, movimiento y apertura de puertas/ventanas) y envía alertas oportunas ante situaciones anormales.

## Segmentos objetivo
- Personas que viven solas.
- Dueños de mascotas.

## Características principales
- Monitoreo centralizado de sensores IoT del hogar.
- Alertas preventivas ante fugas de gas, humo o cambios bruscos de temperatura.
- Dashboard con el estado de la vivienda.
- Interfaz accesible y de fácil uso.
- Modelo freemium con suscripción mensual para funciones avanzadas.
